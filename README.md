# Etch A Sketch

🎨 Interactive drawing board inspired by Etch A Sketch, featuring customizable grids, hover effects, and dynamic sketching interactions.

## Features

* Dynamic grid generation
* Adjustable grid size
* Drawing on hover
* Clear and reset functionality
* Responsive layout
* Interactive sketching experience

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)

## What I Learned

* Advanced DOM manipulation
* Dynamic element creation
* CSS Grid layout
* Event handling
* User input validation
* Building interactive UI components

## Project Goal

This project was built as part of The Odin Project curriculum to practice JavaScript and DOM manipulation by creating an interactive browser-based drawing application.
